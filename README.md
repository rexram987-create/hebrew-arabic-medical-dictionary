# טִבִּי | طِبِّي

מילון רפואי עברי–ערבי ללימוד מונחים שימושיים בערבית הפלסטינית המדוברת.

אתר: https://hebrew-arabic-medical-dictionary.vercel.app/

## מבנה

אתר סטטי ללא שרת, API או מסד נתונים. דף הבית נמצא ב־`index.html`;
הקטגוריות ב־`categories/<category>/index.html`; העיצוב וההתנהגות משותפים ב־`style.css` ו־`app.js`.

- לקיחת דם: 15 מונחים ו־15 הקלטות.
- רופא: 18 מונחים ו־18 הקלטות.
- בית מרקחת: 15 מונחים ו־15 הקלטות.

בכל קטגוריה חיפוש בעברית, בערבית ובתעתיק. החיפוש מתעלם מניקוד ומצורות אל״ף בערבית.

## הוספת מונח והקלטה

1. הוסיפו כרטיס `term-card` עם `he`, `ar` (כולל `lang="ar"`) ו־`tr` בקטגוריה המתאימה.
2. שמרו MP3 ב־`audio/<category>/` עם שם קצר באותיות לטיניות.
3. הוסיפו כפתור `audio-btn` עם נתיב `data-audio`, תווית ייחודית `aria-label` ו־`aria-pressed="false"`.
4. הוסיפו את נתיב ההקלטה ל־`ASSETS` ב־`sw.js` והעלו את מספר גרסת `CACHE`, במיוחד אחרי החלפת הקלטה באותו שם.
5. עדכנו את ספירת המונחים בתיעוד ובדקו בנייד.

שגיאת שמע מפעילה גיבוי של הדפדפן אם הוא זמין. הגיבוי אינו מבטיח הגייה פלסטינית.

## אופליין ועדכונים

ה־service worker נרשם תמיד בשורש האתר, גם בכניסה ישירה לקטגוריה.
דפים, JavaScript ו־CSS מנסים קודם את הרשת ואז משתמשים במטמון; הקלטות משתמשות קודם במטמון.
כל קובץ נשמר בנפרד כדי שכישלון בהקלטה אחת לא יחסום את יתר הקבצים.
דרושה פתיחה מוצלחת באינטרנט לפני שימוש אופליין. קובץ שלא נשמר אינו זמין אופליין.
לאחר גרסת מטמון חדשה, המטמונים הקודמים של טִבִּי נמחקים.

## בדיקות

```sh
node --test tests/*.test.cjs
node --check app.js
node --check sw.js
```

בדקו גם תפריט עם מקלדת, חיפוש בשלוש השפות, התקנה, שמע ופתיחת הקטגוריות בנייד.
הבדיקות האוטומטיות אינן מאמתות איכות הגייה או דיוק תרגומים.
